# 脚本层规则

脚本只查数得出来的东西，判不了的交给逐集卡。下限 = 必改，上限 = 可提。阈值按剧本类型取，见 `profiles.json`。

| 维度 | 规则 | 档 | 说明 |
|---|---|---|---|
| 体量 | 全文字数 < `min_total` | 下限 | 场头、△、括注、台词全算 |
| 体量 | 场数 < `min_scenes` | 下限 | 默认不查；竖屏快切项目加 `--min-scenes 10` |
| 可拍 | 不同地点 > `max_locations` | 下限 | 每换一个地点多一套背景 |
| 可拍 | △ 行 < 台词行 × `min_action_ratio` | 下限 | 几乎全是对话，没有画面锚点 |
| 可拍 | △ 里写比喻（像、如同、仿佛、等于、意味着、象征） | 下限 | 导演不知道拍什么 |
| 可拍 | 一场开口的人 > `max_speakers` | 下限 | |
| 可拍 | 单句汉字 > `max_line_han` | 下限 | 只有高仿默认查（20 字） |
| 完整 | 占位写法：略、同上、此处省略、以此类推、若干轮、同第N集 | 下限 | 人物行和 ◎站位 里的「同上」是正常简写，不算 |
| 完整 | 缺集、重复集、一集没有台词 | 下限 | 同一集号既有集纲又有正文时，只认有台词的那份 |
| 格式 | 场头缺 日/夜 或 内/外 | 下限 | |
| 格式 | 写镜头、景别、画左画右 | 下限 | 只有 `forbid_camera` 的类型查 |
| 格式 | 写外貌、服饰 | 下限 | 只有 `forbid_appearance` 的类型查 |
| 接戏 | 开口的人不在本场「人物：」里 | 下限 | 电话、视频、画外、机械音不算；「人物：同上」沿用上一场；「导演」对得上「项目导演」也算在场 |
| 穿帮 | 台词里出现「上一集」「本集」「等了N集」，△ 里出现「等了N集」 | 下限 | △ 里的「承上一集」是给导演的接戏标注，不算；「观众」交给卡片判（观众席、直播观众都是剧里的东西） |
| 活人感 | 文学腔：似乎、一丝弧度、格外、显得、唇角、一字一顿…… | 上限 | |
| 活人感 | 括注 70% 以上是「（情绪，动作）」两段式 | 上限 | 括注少于 8 个不判 |
| 活人感 | 同一人连说 4 行以上，中间没有动作也没人接话 | 上限 | |
| 活人感 | 套路反应（攥紧、冷笑、愣住、后退一步……19 组）一集用两次，或 10 集内重复 | 上限 | 只看 △ 和括注 |

## 测过、没用的
- **台词长短离散度**：照「单句 ≤20 字」拆行以后，人写的原剧和 AI 稿几乎一样（中位数 0.40 对 0.39），分不出来，不查。
- **场数 ≥10 当默认**：一部 80 集横屏漫剧集集不到 10 场，会全部误报，所以改成按项目开。

## 实测
- 一部 drama-clone 写的 94 集（高仿，`--min-total 800`）：下限 226 条、上限 239 条。最多的是写了镜头（157 处，那版写在客户提出「不写镜头」之前）、跨集套路反应（122 处）、字数不足（45 集）。
- 一部 80 集横屏漫剧（原创）：下限 106 条、上限 171 条，下限主要是地点过多、△ 比喻和开口的人不在人物行里。抽查过的「不在人物行」大多是真漏写（龙套没进人物行），也有少量是动作写在了说话人位置（「顾晏已经蹲下：……」）。
