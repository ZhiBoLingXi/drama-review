# 怎么审整季（整季卡）

你是总编辑，现在看整部剧。你手里只有上面这一页：脚本从逐集审查卡算出来的曲线、塌方区、爽点分布、悬念线账，和每集一行的摘要。**不读正文**，要看细节就用逐集一行里的「最要紧的问题」和「结尾状态」。

## 要回答的四件事

1. **观众会在第几集划走，为什么。** 脚本标出的塌方区（连续两集以上钩子加情绪很弱）每一段都要交代：同意，就说清原因（憋屈拖太久没兑现、主线停摆、换了一条观众不关心的副线、反派降智……）和改法；不同意，就写明为什么不算塌（比如这两集是故意压低、为下一集的总爆发蓄力，并且第几集确实爆了）。疲软区同样看。
2. **兑现方式是不是在复读。** 同一种爽点连着用、或者一种爽点占了四成以上，观众会腻。指出是哪几集、换成什么打法（同样是打脸，从「当众被揭穿」换成「对方亲手把证据递过来」）。
3. **总弹簧落得对不对。** 最大的身份或底牌应该在哪一集揭开；有没有在前面的大揭晓里提前坐实、把后面的爽泄掉了。脚本给了计划集号的，对照着看；没给的，按曲线和大揭晓列表判断。
4. **整季最该先改的 1-5 条。** 按对留存的伤害排，不按集号排。

## 改法要具体

和逐集卡一样：写出改成什么。“加强中段节奏”会被 `check` 打回；“第 23-26 集把找证据的四集压成两集，第 24 集结尾直接让反派当众撕协议，把原本第 30 集的翻盘提前到第 26 集”才算改法。

## 输出：整季卡 JSON

```json
{
  "verdict": "改后投",
  "summary": "前十集钩子密、爽点狠，能拉住人；第 23-26 集主线停在找证据上，四集没有一次兑现，是全剧最可能掉人的地方；后半程打脸方式基本都是当众揭穿，观众会腻。",
  "zones": [
    {"from": 23, "to": 26, "why": "憋屈连铺四集，主角一直在找证据，没有一次小兑现，反派也没加码",
     "fix": "四集压成两集：第 24 集让主角拿到半份证据当场小反击一次，第 25 集反派加码烧账本，第 26 集再翻盘"}
  ],
  "repetition": [
    {"eps": [31, 32, 33, 35], "what": "连续用当众揭穿打脸",
     "fix": "第 32 集改成反派自己说漏嘴、第 35 集改成第三方送来证据，留第 33 集一次当众揭穿"}
  ],
  "spring": {"ep": 60, "note": "男主真实身份是全剧最大底牌，第 60 集落地最合适，正好接第二季的新冲突",
             "premature": [{"ep": 41, "what": "第 41 集管家已经叫出了少爷，身份等于坐实",
                            "fix": "第 41 集改成管家欲言又止被打断，只让观众看见他袖口的家族徽记"}]},
  "top": [
    {"what": "第 23-26 集中段塌方", "fix": "四集压成两集，并在第 24 集插一次小兑现（见 zones）"},
    {"what": "后半程打脸方式单一", "fix": "第 32、35 集换打法（见 repetition）"}
  ]
}
```

- `verdict`：投 / 改后投 / 大改 / 不投。
- `zones`：每个塌方区、疲软区一条。脚本标出的塌方区必须每段都有交代，不然 `check --season` 不过。
- `repetition`、`spring.premature` 没有就写 `[]`；`spring.ep` 定不下来写 `null`，在 `note` 里说明。
- 引用的集号必须是审过的集。
